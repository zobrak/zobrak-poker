ZobraK Poker est un espace personnel de travail autour du poker cash game short-handed.

Le site comporte deux sections principales :

- **Ranges** — consultation des ranges NL2 construites pour le jeu 6-max cash game. Les ranges sont organisées par catégorie (open, 3bet, défense, ISO, squeeze) et par position.

- **Review** — outil de review de mains à partir de hand histories PokerTracker 4. Permet de parser une HH, de structurer l'analyse et de générer un fichier Markdown exploitable.

Ce site est un outil de travail personnel, sobre et sans tracking.
